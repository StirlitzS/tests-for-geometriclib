# Geometric Library (geometric_lib)

## Общее описание решения

Данный проект представляет собой библиотеку на языке Python для вычисления площади и периметра различных геометрических фигур: круга, прямоугольника, квадрата и треугольника.

---

## Описание функций

### circle.py

* **area(r)** — Принимает радиус окружности `r`, возвращает её площадь (π * r^2).
  *Пример вызова:* `area(3) -> 28.274333882308138`

* **perimeter(r)** — Принимает радиус окружности `r`, возвращает длину окружности (2 * π * r).
  *Пример вызова:* `perimeter(3) -> 18.84955592153876`

### rectangle.py

* **area(x, y)** — Принимает стороны прямоугольника `x` и `y`, возвращает его площадь (x * y).
  *Пример вызова:* `area(2, 3) -> 6`

* **perimeter(x, y)** — Принимает стороны прямоугольника `x` и `y`, возвращает его периметр ((x + y) * 2).
  *Пример вызова:* `perimeter(2, 3) -> 10`

### square.py

* **area(a)** — Принимает сторону квадрата `a`, возвращает его площадь (a * a).
  *Пример вызова:* `area(5) -> 25`

* **perimeter(a)** — Принимает сторону квадрата `a`, возвращает его периметр (4 * a).
  *Пример вызова:* `perimeter(5) -> 20`

### triangle.py

* **area(a, h)** — Принимает основание `a` и высоту `h`, возвращает площадь треугольника (a * h / 2).
  *Пример вызова:* `area(3, 4) -> 6.0`

* **perimeter(a, b, c)** — Принимает стороны треугольника `a`, `b`, `c`, возвращает его периметр (a + b + c).
  *Пример вызова:* `perimeter(3, 4, 5) -> 12`
